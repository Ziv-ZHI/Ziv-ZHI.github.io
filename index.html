BURNISH (灵犀智磨) — Collaborative Robotic Polishing Software Suite

lingxi-polish · C++ / Qt 5.15 · the flagship project

A complete host-computer software suite for a collaborative robotic polishing cell: constant-force control with a 6-axis force/torque sensor, EtherCAT real-time control at a 2 ms cycle, hand-eye vision calibration, scan-line trajectory generation, a SQLite process library, an edge gateway, and a WeChat mini program for remote monitoring. The controller firmware is generated by Simulink model-based design and shares a single wire-protocol header with the host.
